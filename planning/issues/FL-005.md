**Sprint:** S0 · **Prioridade:** P0 · **Tipo:** security · **Área:** assets · **Esforço:** 3 SP

## Objetivo
Garantir cadeia de procedência, licenças e segurança dos modelos.

## Implementação
- [x] Usar o registro versionado `assets/registry.csv`.
- [x] Registrar fonte, autor, ID, URL e termos de acesso observados para o candidato.
- [x] Importar o candidato apenas para `ServerStorage` como quarentena; não foi colocado em `Workspace` nem no mapa final.
- [x] Auditar a árvore completa: quatro peças primitivas, nenhum Script/LocalScript/ModuleScript e nenhuma referência externa reportada.

- [x] Modelo sem scripts reportados; nenhum código do asset foi executado.
- [x] Manifest e relatório de auditoria rastreáveis por ID, URL e issue.
