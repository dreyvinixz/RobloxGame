# FL-011 — Completar vertical slice contra alvo de teste

**Sprint:** S1 · **Prioridade:** P0 · **Tipo:** feature · **Área:** gameplay · **Esforço:** 3 SP

## Objetivo
Integrar mapa, movimentação e arma.

## Implementação
- [x] Juntar greybox + rifle + alvo com feedback; alvo simples é criado pelo servidor ao iniciar a arena
- [x] Reset do alvo eliminado pela tecla `T`, validado no servidor
- [x] Cenário reproduzível: dummy com 100 HP e indicador de vida é criado em posição fixa na rota central

## Critérios de aceite
- [x] Usuário entra, move-se, mira, atira, elimina dummy e reinicia teste.

## Evidências e verificação
O usuário confirmou o fluxo anterior no Roblox Studio usando um dummy inserido manualmente: entrou, movimentou-se, mirou, atirou, eliminou o alvo e reiniciou o teste. A FL-011 agora cria o alvo e permite reiniciá-lo com `T`; este novo fluxo reproduzível ainda precisa ser repetido no Studio. Não foi anexada gravação nem captura de logs.
