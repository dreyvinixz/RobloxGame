# FL-021 — Authoritative destructible cover (partial)

**Date:** 2026-10-15

## Implementation

- Arena `CoverCore` parts receive server-owned `CoverHealth`, `CoverMaxHealth`, `CoverState`, and `DestructibleCover` attributes at startup.
- Max health is 100. Validated server ray hits apply the selected weapon's server-computed damage after range falloff. At or below 50 HP state changes to `Damaged`; at zero it changes to `Destroyed`.
- On destruction the server hides the core and armor panels and disables collision and ray queries. Attributes and part property changes use Roblox instance replication; clients have no destruction remote or direct authority.
- `DamageService` routes confirmed ray hits into `DestructibleCoverService`; the core continues to block shots until destroyed.
