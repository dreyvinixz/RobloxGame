# FL-020 — Rifle and pistol (partial)

**Date:** 2026-10-15

## Implemented

- Server-owned `WeaponConfig` now defines `TestRifle` and `ServicePistol` damage, cadence, magazine size, reload, range, headshot multiplier, and linear distance falloff.
- Keys 1 and 2 request equip. The server accepts only configured weapon IDs, rate-limits switching, validates each shot against the equipped weapon, and enforces the selected weapon's range and fire interval.
- Ammunition and reload state persist independently for each weapon; changing weapons does not refill the magazine. Reload applies to the equipped weapon.
- Damage is calculated from the server-side weapon definition and actual server raycast hit distance. The client does not submit damage.

## Expected TTK from configuration

For a 100 HP body target at point-blank range, ideal shot timing gives the rifle four hits / **0.36 s** and pistol three hits / **0.56 s** from first shot to kill. At each weapon's configured maximum range, the expected results are rifle eight hits / **0.84 s** and pistol six hits / **1.40 s**. These values are calculations from weapon config, excluding latency and reload, not measured Studio results. Full parameters are in `docs/WEAPONS.md`.
